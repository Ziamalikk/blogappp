# My Blog App

A modern blog built with Next.js (frontend), Node.js (backend), and MongoDB (database).

## 🚀 Features
- Next.js for fast, SEO-friendly pages
- Node.js backend API
- MongoDB for storing posts and user data
- Responsive design (works on mobile/desktop)

## ⚙️ Setup

### Prerequisites
- Node.js (v16+)
- MongoDB Atlas account or local MongoDB
- Git
